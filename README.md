# POS System - TFA2 (CodeIgniter with MySQL)

Developed by: Shem James Caayon

## Description
This is a CodeIgniter 4 Point of Sale (POS) application that retrieves customer and user account records from a MySQL database using Query Builder Models, transitioning from the static arrays used in TFA1.

## Setup Instructions
1. Clone this repository into your XAMPP `htdocs` directory.
2. Open phpMyAdmin and create a new database named `pos_database`.
3. Import the provided `.sql` database export file into `pos_database`.
4. Open the `.env` file and configure the database credentials to match your local setup. Ensure `app.baseURL` points to the correct local directory path.
5. Launch the application via your browser (e.g., `http://caayontfa2.site.je`).
